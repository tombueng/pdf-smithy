# Colophon

This document was set from plain text by the same program that reads it. No
page in it was drawn by hand and no page was pasted in from anywhere else.

The body is Times at ten and a half points on a fourteen point line, set
justified, with the spaces between words stretched rather than the letters.
Headings are Helvetica. Both are among the fourteen fonts every reader is
required to know, so nothing had to be embedded and the file stays small
enough to send.

The chart, the diagram and the colour study are vector drawings: rectangles,
ellipses and lines with fills, strokes and transparency, placed by
coordinates measured in points from the bottom left of the page. The
photograph is the one thing on any page made of dots.

The form is a real form. The fields were built from a description rather than
drawn, which is how the same layout can be produced again after somebody
moves a label. Two of the fields will not let the form be sent while they are
empty.

The marks on the page of remarks are comments in the proper sense: they sit
beside the page, not in it, and removing them leaves the words underneath
exactly as they were.

The table of contents was written last, from the sections that turned out to
exist rather than the ones that were planned.

## Rebuilding this

The whole document is produced by one script in the repository. If a heading
moves, or the paint changes colour, or somebody finds a better word for the
tide gauge, the script is edited and run again and the file comes out the
same way every time. That is the point of it. A showcase nobody can rebuild
stops being true about six weeks after it is made.

## Not real

Kestrel Island does not exist. Neither does the trust, the warden, the
boatyard, the tide gauge or any of the birds. Every number in this review was
invented to be the kind of number that would be there.
